# Proposals (SWapp)

1. Follow All Thing sop-money-playbook, sop-quote-and-contract and
   sop-sales-tag-actions. Inventory all open proposals and pipeline next actions,
   not only changes since the last scan.
2. Read evidence of sent/viewed/accepted/paid states, signed agreements and
   payment references. A view is not acceptance and a reply is not a signed GSA.
3. Reconcile permitted evidence and lead/task records, using stable proposal
   IDs. Prepare follow-ups and flag paid-but-unsigned, overdue responses and
   missing owner/due dates. Verify writes by reading records back.
4. Sending proposals, invoices or agreements requires Tom's send authorization.
   Keep such tasks pending. Do not change signed or paid flags without proof.
5. Re-read the outstanding pipeline. If current tools cannot inspect proposals
   or evidence, report incomplete coverage and the missing capability.

Related All Thing SOPs: sop-leaving-leads, sop-lead-file.
