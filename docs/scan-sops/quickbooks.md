# QuickBooks

1. Follow All Thing sop-qb-login and sop-money-playbook. Identify the actual
   agent browser/session on Ripley and verify the intended QBO accountant
   account and business. A login in Tom's separate browser does not authenticate
   the agent. If no connected browser is available, report that exact blocker.
2. Verify the session by reading the accountant client list. Inspect pending
   client invitations and outstanding contract checks against SWapp lead IDs.
3. Follow sop-quote-and-contract. Read the actual contract status and signed
   document. An email saying done is only a hint. Record supported evidence;
   do not accept invitations, send/change contracts or change books under scan.
4. Record every item requiring Tom with client/contract reference and next action.
   Preserve the source link. Read-back verifies every permitted record update.
5. Recheck the same session and pending work after login. Until verified,
   report missing access or review work, not a generic permanent login prompt.
