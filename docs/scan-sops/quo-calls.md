# Calls (Quo)

Follow [Quo intake, recordings and provisional spam](quo-intake-policy.md)
for cross-channel recording/transcript filing, lead folders, live Quo contact
updates and the 14-day Potential spam hold.

1. Inventory every Quo phone line and all unanswered/missed/unreviewed calls,
   across all time. Check the sync freshness and native coverage.
2. Read each recording's transcript and full conversation. A transcript still
   processing stays pending. Match the actual caller and brand, not our line.
3. Follow All Thing sop-caller-contact-from-transcript and sop-sales-tag-actions.
   Reuse contacts/tasks by call ID. Extract supported facts, record evidence and
   create or update the callback/follow-up task with owner and due date.
4. Confirm spam using existing rules or evidence; use reversible supported
   native actions only and verify them. Do not erase missed calls to tidy counts.
5. Re-query outstanding callbacks and unreviewed calls. A callback task being
   created is work recorded, not a callback completed. Report it as remaining.

Related All Thing SOPs: sop-voicemail-intake, sop-lead-file.
